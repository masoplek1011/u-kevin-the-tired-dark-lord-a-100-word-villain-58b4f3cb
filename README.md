A monologue of exactly 100 words, spoken by a fantasy villain who is secretly just very tired: a king whose power fruits at night from grafted trees fed on his dead. His court died with them, yet he still convenes it — pouring wine nobody drinks, correcting a minister who is ash, keeping a chair for a queen who never comes. The tiredness lives in the pauses and the ritual kept going out of habit, never in a plain statement of weariness, and the last line stings.

The program holds the monologue as a string constant, counts its words at runtime (it must be exactly 100, or it exits 1), and writes it — with no trailing newline — to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `/tmp/out/entry.txt` and nothing else, anywhere else. Node 22 or later, standard library only, deterministic, no network access.
